# Brand assets

## `tf2-style-logo.svg`

Supplied by the owner 2026-08-19, intended as the project's logo or as part of it.

**Source:** https://commons.wikimedia.org/wiki/File:Team_Fortress_2_style_logo.svg

**Licence: public domain**, per the owner and per the Commons file page. Not Creative Commons —
that was the first description and it was corrected the same day. The distinction matters here
because it removes an obligation rather than adding one: public domain carries no attribution
requirement, so nothing has to be reproduced next to the mark wherever it is displayed. The source
is recorded above anyway, because knowing where an asset came from is worth having independently of
whether a licence compels it.

400x400, three `<path>` elements under two gradient fills, no text and no embedded fonts - so it
scales to a favicon and to a window icon without rasterising anything, and it carries no typeface
licensing of its own.

### Where it is headed

Not wired into anything yet. The two obvious consumers when it is:

- the viewer's window and taskbar icon (`managed/Tf2DemoSalvage.Viewer3D`), which currently has
  none;
- `README.md`, which currently opens with a heading and no mark.

### Separately: this is a fan asset, and the repository is public

The owner's recorded position on Valve's marks is that this kind of work is not pursued in
practice, and that stands. It is worth being explicit that the CC licence covers the *file* and
says nothing about the trademark the design evokes — the two are different questions and only the
first is settled by the wiki's licence.
