Lessons:
- Read the WHOLE engine function before writing "the engine has no shortcut": `_Interpolate` copies a one-entry pair
  at `:1315`; reading only `:1333` produced a fix that regressed the held case.
- A fix whose own test passes can still regress a case no test covers; and an old shortcut can be hiding a second
  defect. Revert and file the pair rather than chase it on a branch about something else.
- An allocation test that takes one least over mixed kinds of step cannot see one kind allocating: time each kind.
- A grouped sabotage can redden the right test for the wrong reason: rerun the break alone.
