beta.64 (a7eb9f98) and beta.65 (f926967c) were published. This handoff supersedes [[handoff-2026-11-08]].

**Merged since beta.65:**
- B679: `r_lightmap_bicubic` is ported to the world shader (`LightMapSample`, `debugModes2.z`). The texel step comes from
  the atlas's `GetDimensions`, where Valve uses the literal 1024x512.
- B550: a seek is the engine's demo skip for sound.
  - Only a reload stops everything: an open, a move back, or a walk that went back.
  - Every skip dispatches only `CHAN_STATIC` sounds and `SND_STOP`, in the frame that reads each batch:
    `RunSkipFrame` calls `SoundPresenter.SkipFrameRead`, then `PlaySkipFrames` dispatches.
  - There are 64 static channels (`AudioOutput.StaticChannels`).
  - The review caught a first port that dispatched at the landing. It would have filled the 64 channels with f12's
    7,782 static one-shots (probe `static-sounds`).
  - If B550 is not on main yet, its branch is `fix/b550-seek-sounds` in `F:/wt-b550`, gated after two reviews.
