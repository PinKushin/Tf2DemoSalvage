Writing a synthetic demo with a current schema, so the live TF2 client can play it for a golden screenshot, is a test tool. It can be sloppy and narrow: one map, one pyro, one shot. D1 does not apply to it. D1 parks Phase 4: a general, schema-agnostic tool that repairs anyone's old demos for the live client.

**Why:** the owner, 2026-09-25, after I cited D1 to decline a synthetic demo: "you creating a synthetic demo, isnt the same as creating a TOOL to fix demos, you can do something sloppy and just working, because its a test tool ... that decision has nothing to do with problem and concept at hand, idk why you used it".

**How to apply:** when a golden reference needs TF2 to play something it can't, build a throwaway demo in a current schema (see [[engine-accepts-authored-demos]]). Don't reach for a parked decision whose subject is a different product.
