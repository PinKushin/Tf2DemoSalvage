Owner, 2026-10-29, after I relayed his running commentary to a recording agent twice (one relay was a misreading that
put a wrong claim into the agent's brief): *"i wasnt telling yyou to correct the agent at all, fuck, stop doing that
without thinking, i was just saying hat i was observing"*.

**Why:** he narrates what he watches during a client run. Treating each line as a directive, then relaying it to an
agent, injected a wrong note ("display not repainting") and a second correction. The agent had its own logs.

**How to apply:** a mid-run sentence about what is on screen gets at most a one-line acknowledgement, and a check of
the logs only if it is a question. No SendMessage to an agent from it. Act only on an explicit ask ("tell it",
"change X", "do Y"). If an observation contradicts the agent's own report, say so to the owner and ask before
messaging the agent. Related: [[owner-input-does-not-affect-rcon-driven-runs]], [[a-picked-option-is-not-a-voiced-decision]].
