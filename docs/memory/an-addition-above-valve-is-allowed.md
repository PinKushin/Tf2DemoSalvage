Parity rule refined: everything the engine does must be done as it does. An ADDITION beyond it (e.g. D217's team/class backfill table, filling ticks before the demo states them) is allowed when the owner wants it.

**Why:** owner, 2026-10-14, on keeping Backfill under checkpoints: "i dont really mind a divergence if its a added feature, we cant drop anything valve does, adding to it to be better is OK, but can come with own problems down the road,, because theres probably a reason valve doesnt do it".

**How to apply:** never remove or alter engine behaviour to make an addition fit. Record each addition as one (DECISIONS, owner's words) with the open question of why Valve does not do it. Prefer off-switchable. An addition that conflicts with engine behaviour is a divergence and the engine wins. Related: [[valve-parity-is-the-first-principle]], [[rewind-is-ours-parity-first]].
