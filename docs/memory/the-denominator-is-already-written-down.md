**`docs/SDK-COVERAGE.md` is generated from `source-sdk-2013` by `SdkCoverageTests` and lists, by
name, every declared thing this project does not handle.** Material parameters, BSP lumps, studio
structures, net messages, temp entity effects. It is committed, it cannot drift from the engine
without the engine changing, and it is regenerated by running that test.

**Measured 2026-08-25.** Asked whether we were missing BSP lumps, I scanned `engine.dll` for
`Mod_Load*` literals, found 31 loaders, and worked out that six were unread. Good technique, real
answer — and the file already said:

```
## BSP lumps
**27 of 66** declared by the engine are handled here.
Not handled: ... LUMP_VERTNORMALINDICES, LUMP_VERTNORMALS, ...
```

The owner: *"yep thats why i say conformance tests first too"*. The conformance test had done its
job. Nobody read the output.

**So the rule pays at the point of ASKING, not only at the point of writing.** A conformance test
exists to hold the denominator before our own data can bias the question — which means consulting it
FIRST, before a decompiler, a binary scan, or a fresh count. Deriving an answer that is already
committed is not verification, it is re-work that happens to agree.

**How to apply:**

- Any "are we missing / do we handle / how many of X" question about Valve's surface: read
  `docs/SDK-COVERAGE.md` before anything else. `docs/CONFORMANCE.md` is its companion and carries
  what each gap COSTS, which the counts deliberately do not.
- **The denominator is extracted; the numerator is hand-maintained.** `ImplementedLumps()`,
  `ImplementedStructures()` and their siblings are lists somebody edits. Adding a reader without
  adding its name fails nothing and silently understates coverage — so a new reader is TWO edits.
- A lump counts as handled when it is READ, not when it is drawn ([[decode-must-be-total]], D93).
- The report is passive: it is written by a test that asserts only that the EXTRACTION found enough
  to be real. Nothing fails when coverage drops, so nothing prompts you to look — you have to.
