# Measurement 2026-10-22: TF2 against the viewer on f12, paired again after findings 89-95

**Status: written and committed before the run.** Sections above `## Result` are fixed from here; deviations go under Result.

## Observation

The previous pair (`2026-10-21-tf2-vs-viewer-f12.md`) read TF2 at 159-239 fps (mean ~190) against the viewer's 66-69 fps steady,
same demo, same player (gummo, first person), 1280x720: a ratio of about 2.8x. Since then findings 89-95 (burst copy, dynamic light
merge, threaded particles, exposure by occlusion queries and others) changed the viewer's frame, and agents' own `--measure` runs
on a quiet machine now report about 11-13 ms a frame (80-90 fps). The owner, 2026-10-22: *"we need and want better than tf2 fps
because we are still missing stuff"*. Nobody has re-paired the two since the changes.

## Question

Today, on the same machine in the same state, what is the ratio of TF2's frame rate to the viewer's on `tf/f12.dem`, same tick
region (from tick 30000), same camera (first person of the same player, gummo), same 3D view size (1280x720)?

## Prediction

- Viewer steady 75-95 fps; TF2 150-250 fps (as before; nothing changed in TF2); ratio 1.7x-3.0x.
- Inconclusive (rather than falsified) if the viewer's before and after runs disagree by more than 15% (drift), or TF2 is ever found
  unfocused or not on gummo's first-person view at a reading.

## Method

Order, all in one session, nothing else running under the lock: **viewer run A, TF2 playback 1, TF2 playback 2, viewer run B**
(the viewer before and after TF2 is the drift control; two TF2 playbacks are its repeat).

**Viewer** (build of `origin/main` `ae3d5e39`, Debug, as the owner runs it), each run:

```
TF2VIEW_AUTOPLAY=1 TF2VIEW_VIEWPORT_SIZE=1280x720 pwsh C:/Users/pinku/source/repos/PinKushin/run-exclusive.ps1 \
  managed/Tf2DemoSalvage.Viewer3D/bin/Debug/net10.0-windows/tf2demoview.exe D:/measure-f12/f12.dem \
  --tick 30000 --spectate gummo --first-person --measure 20 +fps_max 0
```

The figure is the `--measure` report's mean frame time over the 20 playback seconds, converted to fps, plus the per-second samples
with the first five dropped (steady). `D:/measure-f12/f12.dem` is the space-free copy of TF2's own `tf/f12.dem` (34,560,994 bytes)
made out of the game folder on 2026-10-21; nothing is copied into the game folder.

**TF2** (the shipped client through the `mcp__tf2__*` tools; launch only if no client answers), each playback:
1. Read and record before changing: `fps_max`, `mat_vsync`, `cl_showfps`, `engine_no_focus_sleep`, `mat_hdr_level`,
   `sv_allow_wait_command`, `spec_autodirector`, and the video mode. Set windowed 1280x720 if it is not, `fps_max 0`, `mat_vsync 0`,
   `engine_no_focus_sleep 0`, `cl_showfps 2`.
2. `playdemo f12`, `demo_gototick 30000 0 0` (forward only, never paused), then `spec_player gummo` with first-person spec mode
   (f12 is a SourceTV recording: the default camera roams, which read a wrong low number last time).
3. One screenshot to prove the camera is gummo's first person (viewmodel in frame, target id), then readings: a screenshot every
   ~5 s over ~25 s of playback, the `cl_showfps 2` figure read off each picture, and the foreground window checked and written at
   each reading (must be `tf_win64`).
4. After both playbacks: restore every ConVar read in step 1 and read them back, quit TF2.

**Machine load per run:** `(Get-CimInstance Win32_Processor).LoadPercentage` before and after each run (viewer and TF2), and GPU
utilisation from `nvidia-smi --query-gpu=utilization.gpu --format=csv` alongside, if present.

## Control

- **Drift:** viewer run A and run B (before and after TF2) must agree within 15% on mean fps, else the ratio is inconclusive.
- **TF2 repeat:** playback 1 and playback 2 means must agree within 15%, else reported as spread only.
- **Instrument asked for a known value:** once, `fps_max 60` in TF2: `cl_showfps 2` must read about 60, then back to `fps_max 0`.
  On the viewer side, ticks advanced over the window should be about 66.7 x 20 = 1,333.
- **The camera:** a reading counts only if TF2 was foreground and the picture shows gummo's first person; otherwise it is listed
  and excluded.
