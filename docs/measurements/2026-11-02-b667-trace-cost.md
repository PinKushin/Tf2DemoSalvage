## The production build, `LevelLighting.From` (added to the probe after the runs above)

The probe gained a pass that builds lighting with `LevelLighting.From`, including the production delegate and the computed
ambient, and reads `StaticStateBuildTicks` over the same points. That counter is the one the viewer's "static-prop lighting
at load" line reports. Same hand restore for "before".

| `LevelLighting.From`, static states | before | after |
|---|---|---|
| koth_toxic, 2,212 (five runs each) | 3,914 / 3,828 / 3,944 / 3,920 / 3,858 ms, mean 3,893 | 3,530 / 3,653 / 3,502 / 3,620 / 3,700 ms, mean 3,601 |
| cp_process_f12, 1,347 (two runs each) | 963 / 1,045 ms | 959 / 952 ms |

The same runs' isolated traced-minus-untraced delta on koth_toxic: 903 / 879 / 882 / 918 / 857 ms before (mean 888), and
556 / 708 / 562 / 542 / 573 ms after (mean 588). On f12 the replayed displacement sweep went from 135–136 ms to 66–67 ms, with
the checksum `c59f5915751f641b` both sides over 47,923 rays.

**`From` reaches 3.9 s, not the viewer's 5.6 s,** so the control does not reproduce the viewer's figure. The ambient's own
rays are the rest of `From`'s time: about 2.8 s, unchanged by the fix, so they do not go through `DisplacementCollision`.
Arithmetic: From minus the untraced build minus the traced delta.

One Release run with groups of four gave a 247 ms sweep against 210 ms for eight in the run before it. That is within this
machine's noise, so eight was kept.
